# Redis Read Through Cache - Todo Application

## Overview

A learning project to understand Redis caching using FastAPI and MongoDB.

The application implements a Todo API where:

1. FastAPI receives requests.
2. Redis acts as a cache layer.
3. MongoDB stores permanent data.
4. Frequently accessed data is served from Redis.

## Tech Stack

- Python
- FastAPI
- MongoDB
- Redis
- Docker
